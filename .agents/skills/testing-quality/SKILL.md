# Testing & Quality Skill

## Purpose
Enforce test discipline across unit, lint, typecheck, build, and E2E gates.

## Workflow
1. Write failing red unit/integration tests before implementing features.
2. Execute tests and verify clean green output.
3. Verify test runner evidence and avoid false-green claims.
