# Agent Handoff Skill

## Purpose
Write structured handoff documents to transfer context cleanly between agent roles.

## Workflow
1. Summarize completed tasks and remaining work.
2. List changed files, test results, and evidence.
3. Record active leases and open questions for the next agent.
