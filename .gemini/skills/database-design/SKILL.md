# Database Design Skill

## Purpose
Design relational and document data models, define migration scripts, and maintain ERDs.

## Workflow
1. Update schema definition (e.g. Prisma or SQL migration).
2. Use conditional updates (`gte`, `status: PENDING`) for atomic transitions.
3. Update data dictionary and ERD diagrams.
