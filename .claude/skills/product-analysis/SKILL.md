# Product Analysis Skill

## Purpose
Analyze completed project briefs and translate requirements into structured user stories and traceability matrices.

## Workflow
1. Read project brief at `docs/product/PRODUCT_BRIEF.md` or client brief.
2. Extract goals, user stories, and acceptance criteria.
3. Update `docs/product/REQUIREMENTS_TRACEABILITY.md`.
