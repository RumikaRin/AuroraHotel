# Project Onboarding Skill

## Purpose
Guide agents through analyzing a repository, reading source-of-truth files, and understanding context.

## Workflow
1. Read `project-manifest.yml` and `AGENTS.md`.
2. Inspect `docs/INDEX.md` and relevant architecture specs.
3. Verify directory structure and commands in `package.json`.
4. Report current project state and task boundaries.
