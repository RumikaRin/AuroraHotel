# Definition of Done for Aurora Hotel

A change is done only when:

- acceptance criteria are satisfied without unresolved critical assumptions;
- source, contracts, docs, diagrams, and traceability agree;
- input validation, authorization, tenant/owner scope, and redaction are tested;
- concurrency, retry, replay, and failure behavior are tested where relevant;
- migrations and rollback/recovery steps are reviewed;
- accessibility, performance, privacy, and observability impacts are addressed;
- lint, typecheck, test, build, e2e pass in order with retained command evidence;
- no managed-file drift, stale ERD/render, broken link, secret, or high finding remains;
- the handoff states exact changes, evidence, residual risks, and next action.
